# TdF 学习底层逻辑

## 每个知识点怎么学

1. **先用当期讲义建立因果链。** 从原图指出工件、工具和实际运动，再说清材料怎样流、为什么能成形、哪里先达到极限，以及题目要读图、画图、选型还是计算。概念用中文讲透，工艺名和考试答案保留德语。
2. **按讲义页码选实际 Anki 卡。** 先对照卡片正反面和图，再按当前小节一次问一个知识点。卡片有图时展示对应图，先认部件、箭头和坐标，再解释理由。两套牌组同一考法只练一次，答案有冲突时回查原页。下文 ID 可在 [Anki 内容包](../anki/README.md) 的 `notes.json` 中按 `sources.note_id` 查找，同一个 ID 可能有不同版本。
3. **按题目要求练输出。** 定义用德语关键词短答，工艺题标箭头与成形开口，极限题指出失效位置和原因，公式题先写原式、符号与条件，再完整代入。带做时由助手代算机械步骤。独立复测时换图或换工况，一次检验一个判断。跟着提示答对记为引导完成，独立掌握按实际作答记录。
4. **按本周课件覆盖收尾。** 下表的先练项用于安排顺序。低优先细节仍按课件完成概念、公式与符号、条件、应用及易错点的核对。旧题线索沿用[考试重点清单](2026-11-04-截至当前讲义的考试重点清单.md)，卡片只作为练习证据，考查范围以课程公告为准。

### 容易从旧卡背错的地方

- **4.3 裂纹和失稳。** 裂纹卡把不同机制压在一张卡里。最大拉应力与裂面方向的说法限于拉裂解释，第 3 页还有受压工况下的 Schubrisse（剪切裂纹）。弯曲卡的外侧增厚、内侧减薄表述先搁置，按原图和受力解释，外弧通常拉伸趋于减薄，内弧受压趋于增厚。工具磨损卡的概括也要用第 10–11 页的具体失效现象补足。
- **4.6 Napf-Rückwärts。** 第 6 页小标题为 Napf-Rückwärts-Fließpressen，正文首词却写 Vorwärts。定方向时以原图和材料相对冲头的实际流动为准，正式讲解时再核成形开口对应的部件。模具加固卡有时笼统写成“切向拉应力”，必须分清装配后模芯的环向预压和外圈的环向拉应力。
- **4.7 温度卡。** 温度范围练读图，具体材料与工况按课件或题给数据判断。优先掌握升温降低变形阻力与局部初熔的两条因果链。工艺定义、润滑、优点等旧卡可作补充，用当前课件或对应题目核实具体说法。
