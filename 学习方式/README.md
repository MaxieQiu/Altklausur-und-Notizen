# 学习方式与技能

本目录用于集中整理跨课程学习方法，并存放今后添加的学习辅助 skill。具体课程资料、学习进度和掌握度仍保存在各课程目录中。

## 现有学习方式

完整规则以根目录 [AGENTS.md](../AGENTS.md)、[通用考试复习项目模板.md](../通用考试复习项目模板.md) 和用户最新要求为准。以下仅为入口摘要：

- 德语保留题目和考试术语，中文解释概念、思路和纠错；新术语先解释。
- 按实际课件核对小节覆盖，必要概念、公式、条件和应用不能省略。
- 公式重点讲符号含义、适用条件与如何使用，默认省略证明。
- 机械运算可代算，保留关键代入过程；方法选择与理解仍让用户参与。
- 优先展示课件或题目原图，按需要补充可视化。
- 教学覆盖与掌握度分别记录，给公式或提示后完成不等于独立掌握。
- “继续”从当前未完成内容接续；具体断点查对应课程 handoff。

## 学习辅助 skill

[技能索引](skills/README.md) 记录各技能的用途和入口。首次使用所选技能时，读取对应的 `SKILL.md`。

课程讲解和苏格拉底式提问可以穿插使用。讲新内容时，按课件讲清必要的概念、公式、条件和代表应用，期间可以用短问题让用户预测结果或解释原因。讲完一个重点后，用提问或变式检查能否独立选方法和应用。用户主动要求测验或复习时，可以直接从诊断问题开始。

提问聚焦方法、适用条件和物理含义。用户卡住时直接补充必要解释，再用另一问检查理解。教学覆盖与独立掌握仍分别记入课程交接。

项目与课程最新入口见 [项目交接索引](../docs/handoff/CURRENT.md)。
