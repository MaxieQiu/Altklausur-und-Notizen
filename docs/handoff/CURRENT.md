## 使用方式

本文件只保存项目级索引和跨课程规则，不再用某一门课程的状态覆盖其他课程。

开始课程任务时：

1. 读取根目录 `通用考试复习项目模板.md`；
2. 读取本索引；
3. 识别当前课程目录；
4. 读取该课程的 `handoff/CURRENT.md` 和最近相关 session。

执行“收工”时，应根据本次对话和实际文件识别涉及的课程，只更新对应课程的 handoff；若涉及多门课程，分别记录。
