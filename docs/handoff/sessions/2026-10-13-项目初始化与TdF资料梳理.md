## 重要内容

### 复习方法

- 先核对专业、教师、学期、考试范围和试卷结构。
- 当前教师和同专业的最新资料优先于旧卷或其他专业试卷。
- 新题型先完整讲解，已学题型无提示逐步作答。
- 只有无提示独立完成的内容才能计入保守预计得分。
- 后期复习重点转向个人易错步骤和高价值题型。

### TdF 课程

- 课程名称：`Technologie der Fertigungsverfahren`。
- 第一课重点包括 Fertigung 的定义、DIN 8580 六大工艺分类、制造路线选择，以及 Technologie / Verfahren / Prozess 的区别。
- TdF I 为 2026-10-13 至 2026-12-07；TdF II 自 2026-12-08 开始。
- 合并考试时间为 2027-03-01 08:00-10:00，TUCan 自 2026-11-15 开放报名。
- 2026-11-30 和 2026-12-01 因 EMB 无课。

### 跨设备延续

- GitHub 同步项目文件，不会自动把本地 Codex 对话逐字写入仓库。
- `CURRENT.md` 保存最新完整状态；`sessions/` 保存每次工作的进度和重要内容。
- 新设备拉取仓库并打开项目后，Codex 会根据 `AGENTS.md` 自动读取交接资料，无需重新说明工作方式。
