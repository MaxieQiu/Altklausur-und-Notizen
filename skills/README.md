## 技能怎么配合课程讲解

讲新内容时，按课件讲清概念、公式符号、方向、适用条件和代表应用。保留德语题目及考试术语，用中文解释和纠错。优先展示课件或题目原图，机械运算可代算并保留关键步骤。

讲解中可以穿插短问题，让用户预测结果或解释原因。讲完一个重点后，用提问或变式检查能否独立选方法和应用。用户主动要求测验或复习时，可以直接从诊断问题开始。卡住时补充必要解释，再用另一问检查理解。

课程交接分别记录教学覆盖和独立掌握。用户说“继续”时，从当前未完成的内容接续。
