完整教学规则见 [AGENTS.md](../AGENTS.md) 和 [通用考试复习项目模板.md](../通用考试复习项目模板.md)。具体课程资料、学习断点和掌握度见 [项目交接索引](../docs/handoff/CURRENT.md)。

## 技能怎么配合课程讲解

1. **用 teach 确定当前要学会什么。** 从课件、课程交接和用户刚才的作答确定一个可观察的目标，例如“能从德语过程名称判断曲线的起点、形状和方向”。把实际困难作为起点。长题按全科读题规则先定位当前小问的交付物，再找这一问需要的原文条件、原图或表格。
2. **先把新概念接到实物上。** 用中文说清是谁在动、什么被限制、哪个量因此变化，再把这些量和课件公式逐项对应。交代适用条件、方向和符号。保留德语题目与术语。用户要求代算时，依次给原式、完整代入、关键中间步骤和结果。用户已经理解的简单环节合并推进。
3. **用 socratic-tutor 把真正的判断留给用户。** 从已有作答定位薄弱环节。只有需要区分两种理解时，才在揭晓前问一个有区分度的问题，例如“哪个词决定这条线是竖直的，哪个词决定向上还是向下”。提问后等用户回答。根据其理由指出已经说对的部分和缺的前提。主动要求系统测验或练到掌握时，按技能做逐题诊断、子技能图、间隔复测和综合检查。
4. **用 wait-what 修复当前卡点。** 用户说太快、没懂或问的是原式时，停在当前步骤。先确认他指的是哪个量或哪一步，补出缺失的物理前提或中间式，再用原图、具体数值或直观场景换一种讲法。用户指定写法时直接沿用，例如 TM3 用坐标对写向量，机械正负按坐标规则代算。
5. **用作答证据决定下一步。** 课程交接分别记录教学覆盖与独立掌握。听懂、提示下完成、无提示完成分别记录。稳定独立应用至少要有两次独立证据，其中一次是无提示回忆或迁移。用户说“继续”时，从当前未完成的知识或小问接续。

## 每轮怎么运行

每个小问开头给出原题相关条件的截图，并列出本问要用的题给量、原符号和单位。上一问算出的结果单独标明来源。条件在题图或表里时，展示相应区域。

| 用户当前要做什么 | 回合怎么开始 | 回合完成的依据 |
| --- | --- | --- |
| 读资料，晚点学 | 按课程核对版本、目录和正文，抽查关键图、表和公式 | 知道资料覆盖什么，以及接在哪个旧断点之后 |
| 学讲义 | 看一页或一小段原图，从真实物体、动作和约束切入 | 当前概念、原式、符号、条件和一个代表应用已讲清，并标出后续内容 |
| 带做练习 | 展示当前德语小问和必要图，短译交付物，再从题干定位证据 | 交出当前小问要的图、值或判断，写清证据到结果的链条 |
| 自己做、要测验 | 从有区分度的题开始，一次一个问题，记录给过哪些提示 | 用户给出理由，反馈能指出具体是哪项能力过关或待复测 |
| 太快、没懂、要通法 | 停在当前步骤，定位是词汇、物理含义、符号、方法还是代入卡住 | 重新讲清这一处，能用同一规则处理一个邻近情况，或按用户指示继续 |

带做时采用「当前要交什么 → 原文证据 → 实际含义 → 原式与完整代入 → 当前结果」。只展示本轮需要的内容。长题保留可打开的原题，避免整页题干挤在关键词前面。公式已经讲过也在当前计算前重列。用户说“继续”时做下一步，遇到关键判断才单独问。

### 三门课的实际改法

- **TT 长题。** VÜ03 Aufgabe 1(a) 先摘 `Skizzieren … qualitativ … p,v-Diagramm`，翻译成“画定性循环图”。画图证据只取四段过程和理想气体条件。先用“活塞往里推，温度保持不变”解释第一段，再用 `p = RT/v` 定曲线和方向，更新图。涉及 `isochore Erwärmung` 时，把“体积固定”和“温度上升”分别对应到横、纵轴。
- **TM3 相对运动。** 先在原图指出 O、Q、P，写清位置从哪里量起。向量用坐标对，先列公式表原式，再把各坐标完整填入。例如平面绕固定中心匀速转时，对位置坐标 `(x₁, x₂)` 用 `(−ωx₂, ωx₁)` 求牵连速度。正负由坐标式算出来。留给用户的判断是哪个向量该从 O 量、哪个从 Q 量。
- **MM1 轴与支承。** 从减速电机剖视图追两条路线：动力怎样经轴到负载，横向载荷怎样经支承到外壳。再对照原式解释扭矩、截面量、刚度与变形。检查时换一个载荷位置，让用户说明先确定哪个距离，而不是重复背元件名字。

### 学习证据怎么带到下一轮

按现有课程交接规则保存四项：**资料和当前步骤、已讲与已应用的内容、用户作答证据与所获帮助、下次入口**。把一次正确判断记录为具体证据，例如“能根据题干的 isochor 判断比体积不变”。若方向由助手补出，就分别记录。系统测验时再维护子技能图和间隔复测。课程覆盖清单仍按实际课件逐项核对。
